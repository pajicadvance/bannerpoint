# Bannerpoint

Bannerpoint allows turning banners into waypoints that show up in the locator bar. Waypoints can be made by either naming the banner in an anvil and placing it, or by binding it to a map. Both methods can be toggled in the config. Waypoints made this way have unique icons with a color matching the banner's base color. To deactivate the waypoint, simply break the banner or remove it from the map it's bound to. The maximum range of banner waypoints can be configured, with the default being the same as the maximum range of player waypoints (60 million blocks).

Bannerpoint requires [Fzzy Config](https://modrinth.com/mod/fzzy-config) and all of its dependencies.

Bannerpoint can be used as a fully server-side mod, but requires a resource pack on the client for banner waypoint icons. The resource pack can be installed either by simply downloading it from additional files and enabling it on in the client, or if running a Fabric server, by installing [Polymer](https://modrinth.com/mod/polymer) on the server and turning on Auto Host, which will automatically prompt connecting clients to download the resource pack.
